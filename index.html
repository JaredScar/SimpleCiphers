The lesson

What these machines actually do

What is encryption?

Encryption turns a readable message, the plaintext, into ciphertext that is useless without the key. It does not stop someone from intercepting the message. It stops them from understanding it. With the key, reversing the steps is easy. Without the key, it is supposed to be painfully hard.

Encryption on Wikipedia

What is a cipher?

A cipher is the procedure itself: a series of steps that swaps or rearranges letters. A code is different. Codes swap whole words using a codebook. Ciphertext still carries the entire message, just not in a form you can read until the steps run backward.

Ciphers on Wikipedia

Shift

Caesar cipher

ABC → DEF

Every letter slides the same number of places. A shift of 3 turns A into D.

History and how it breaks

The Caesar cipher is one of the simplest and most widely known encryption techniques. Julius Caesar used it in private correspondence, which is where the name comes from. The key is the size of the shift. There are only 25 useful shifts, so a computer can try them all in milliseconds. In modern practice it offers no communications security.

Transpose

Rail-fence cipher

W E A R E

Letters zigzag down a set of rails, then each rail is read left to right.

History and how it breaks

The rail-fence cipher, sometimes called the zigzag cipher, is a transposition cipher. The name comes from the path the letters take. The key is the number of rails. It has to be at least 2, and no more than the number of letters. That is a small search, so the cipher is weak enough to solve by hand.

Polyalphabetic

Vigenère cipher

ATTACK LEMONL LXFOPV

A keyword picks a different Caesar shift for each letter.

History and how it breaks

The Vigenère cipher weaves several Caesar ciphers together, one for each letter of a keyword. It is easy to understand and it resisted a clean public attack for about three centuries. In 1863 Friedrich Kasiski published one. Repeated words are sometimes encrypted by the same key letters, which leaves repeated groups in the ciphertext. The distance between those groups suggests the key length.

With a normal alphabet the math is commutative. If the key length is known, or guessed, you can peel the key off. A probable word in the plaintext makes that much easier. Short messages give the attack even more to hold onto. Brute-forcing the keyword itself is a different problem: this bench will decrypt Vigenère only when you already know the keyword.

Substitution cipher

A→Q B→W C→E

Each letter is replaced by one other letter. There is no single shift.

History and how it breaks

A simple substitution cipher replaces every letter with a different letter: A might become Q, B might become W, and so on. The key is the full alphabet, not a number. There are enormous numbers of possible alphabets, but the cipher is still weak. Letters in English do not appear equally often.

The usual attack is frequency analysis. The chart below compares your message with typical English. E, T, A, O, I, and N usually lead. Guess a few of those, form partial words, and the rest of the key starts to give way. This bench will apply a key you supply. It will not search the 26 factorial possibilities for you.
